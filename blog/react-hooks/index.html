React hooks

Hooks changed React forever. They turned class components into relics and gave functions the ability to remember state, run side effects, and tap into React's lifecycle — all without this.

Think of Hooks as plugins for functions: little superpowers you can attach to make them smarter.

🎭 What are hooks, really?

Simple answer: Functions that let React components "hook into" state and lifecycle features.

Real answer: A way to reuse logic without classes, inheritance, or wrapping your app in HOCs.

Imagine every component is a musician. Hooks are the instruments they pick up:

useState 🎹 → Memory
useEffect 🥁 → Side effects
useContext 🎸 → Shared state

⚡ The core hooks you can't ignore

1. useState — Memory in Your Component

const [count, setCount] = useState(0);

Think of it as: A sticky note where your component remembers things between renders.

2. useEffect — Side Effects Done Right

useEffect(() => {
  document.title = `Count: ${count}`;
  return () => document.title = "React App"; // cleanup
}, [count]);

Runs after render, great for fetching data, subscribing/unsubscribing, updating the DOM.

Think of it as: "Do this _after_ painting the screen."

3. useReducer — State Management Without Redux

const [state, dispatch] = useReducer(reducer, { count: 0 });

Think of it as: A more structured useState for complex logic.

4. useContext — Escape Prop Drilling Hell

const theme = useContext(ThemeContext);

Think of it as: A walkie-talkie 📡 — pass info deep into components without endless props.

5. useRef — A Box That Doesn't Re-render

const inputRef = useRef();

Stores values without triggering re-renders. Great for DOM nodes, timers, previous values.

Think of it as: A secret drawer that React ignores when rendering.

🎯 Custom hooks: your own superpowers

Hooks don't stop at React's built-ins. You can build your own:

function useOnlineStatus() {
  const [online, setOnline] = useState(navigator.onLine);

  useEffect(() => {
    const update = () => setOnline(navigator.onLine);
    window.addEventListener("online", update);
    window.addEventListener("offline", update);
    return () => {
      window.removeEventListener("online", update);
      window.removeEventListener("offline", update);
    };
  }, []);

  return online;
}

🚨 Common pitfalls

Infinite Loops in useEffect

// ❌ Bad - causes infinite renders
useEffect(() => {
  setCount(count + 1);
}, [count]);

Overusing Context — Use it for global data (auth, theme), not every prop.

Hook Rules — Always use Hooks at the top level, never inside loops or conditions.

🔥 Pro tips

  • Write custom hooks to isolate reusable logic
  • Use useCallback and useMemo only when performance is actually an issue
  • Keep components small and focused
  • Extract complex state logic into useReducer

🚀 The bottom line

React Hooks make functional components stateful, powerful, and reusable.

The Hook mindset: Keep components small, extract logic into custom hooks, embrace composition over inheritance.

Hooks aren't just a feature — they're a philosophy: functions should be powerful enough to build entire apps.
