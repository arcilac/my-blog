Ultracite

You've probably noticed how linting and formatting can become bottlenecks as your codebase grows. Ultracite tackles this exact problem — a Rust-based tool that combines linting, formatting, and performance in a single package.

🚀 What is ultracite?

Ultracite is a next-generation code quality tool written in Rust that combines:

  • Ultra-fast linting (10-100x faster than ESLint)
  • Instant formatting (comparable to Prettier, but faster)
  • Zero configuration setup
  • Plugin compatibility with existing ESLint rules
Think of it as ESLint + Prettier + Performance steroids, all in one package.

📦 The performance problem

Traditional JavaScript tooling struggles with larger codebases:

# The painful waiting game
$ eslint src/ --fix
⏳ Linting 500 files... (12.3s)
⏳ Fixing issues... (4.2s)
✅ Done! (16.5s total)

For developers, this means:

  • Interrupting your flow while tools catch up
  • Skipping pre-commit hooks because they're too slow
  • Less frequent code quality checks
  • Procrastinating on refactoring large codebases

⚡ The ultracite way

With Ultracite, that same operation becomes:

# The speed you've been craving
$ ultracite check src/ --fix
✅ Linted and fixed 500 files (0.8s)

Key advantages:

  • Native performance thanks to Rust
  • Parallel processing of multiple files
  • Incremental checking — only processes changed files
  • Smart caching to avoid redundant work

🛠️ Getting started: zero to hero

Installation

# Via npm (includes pre-built binaries)
npm install -g ultracite

# Or use npx for one-off runs
npx ultracite check .

Basic usage

# Check for issues
ultracite check src/

# Fix auto-fixable issues
ultracite check src/ --fix

# Format code (Prettier-style)
ultracite format src/

# Watch mode for development
ultracite check src/ --watch

Configuration

// ultracite.config.json
{
  "rules": {
    "no-unused-vars": "error",
    "prefer-const": "warn",
    "max-len": ["error", { "code": 100 }]
  },
  "format": {
    "semi": true,
    "singleQuote": true,
    "tabWidth": 2
  }
}

🔄 Migration: from ESLint/Prettier

Ultracite makes switching painless:

# Auto-migrate your existing config
ultracite migrate --from eslint

# Import your .eslintrc.js rules
ultracite migrate --config .eslintrc.js

Most ESLint rules work out of the box, and Ultracite's formatter is Prettier-compatible by default.

Developer impact:

🚨 Common gotchas

Not everything is perfect:

  • Some complex ESLint plugins might need adaptation
  • Custom rules require Rust knowledge to extend
  • Memory usage can spike on extremely large monorepos
  • Still early ecosystem compared to ESLint

Pro tip: Run Ultracite alongside ESLint during migration to catch edge cases.

📎 Final thoughts

Code quality tools shouldn't slow you down — they should accelerate your workflow. Ultracite proves that you don't have to choose between thorough code analysis and developer productivity.

Your code deserves tools that are as fast as your ideas.
